## Columns used

From each event entry we read (source-frame where applicable):
`commonName`, `catalog.shortName`, `GPS`, `chirp_mass_source`,
`total_mass_source`, `mass_1_source`, `mass_2_source`, `final_mass_source`,
`luminosity_distance`, `redshift`, `chi_eff`, `p_astro`, `far`, and the
asymmetric `*_lower` / `*_upper` uncertainty fields for jitter controls.

## Derived columns and selection cuts

Built by `scripts/build_gwtc_table.py` into `tables/gwtc_events_clean.csv`:

- `M_chirp` = `chirp_mass_source` (fallback: computed from component masses).
- `M_total` = `total_mass_source` (fallback: `m1_source + m2_source`).
- `observing_run`: assigned from `GPS` using standard LVK run windows
  (O1, O2, O3a, O3b, O4a, O4b). Approximate boundaries; declared in the script.
- `source_class`: coarse mass-based heuristic with a ~3 M☉ NS cutoff
  (`BBH` / `NSBH` / `BNS`). **Not an authoritative LVK classification.**
- `is_primary_entry`: deduplication flag — the highest-preference catalog entry
  per `commonName`, used for the cumulative view (avoids double counting events
  appearing in multiple catalog releases).

## Event counts before / after cuts

- Raw event entries: **671** (across 17 catalogs).
- Unique events (by common name): **433**.
- Cumulative deduplicated primary entries: **433**.
- Cumulative deduplicated with `p_astro >= 0.5`: **386**
  (matches the GWTC-5.0 abstract's "roughly 390 transients").
- Declared-primary `M_chirp` analysis subset (finite positive `M_chirp`,
  cumulative, `p_astro >= 0.5`): **277** events.

## Reproducing the fetch

```bash
python scripts/fetch_gwtc_catalog.py        # re-download + re-hash
python scripts/inspect_catalog_schema.py    # audit fields / fill rates
python scripts/build_gwtc_table.py          # rebuild clean table
```

The SHA-256 will change if GWOSC updates the upstream catalog; re-run and
record the new hash. Use `--offline-ok` to reuse a cached payload when offline.
